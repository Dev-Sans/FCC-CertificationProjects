## 1. User Configuration Manager  
A simple Python project that manages user settings using dictionaries.  

### About the Project  
The User Configuration Manager allows users to add, update, delete, and view settings. It uses <ins>Python dictionaries</ins> to store setting names and their corresponding values.  
This project focuses on practising <ins>Python functions, dictionaries, tuples, conditional statements, loops, and string manipulation</ins>.  

### Features  
- **Add Settings:** Adds a new setting if the name doesn't already exist.
- **Update Settings:** Changes the value of an existing setting.
- **Delete Settings:** Removes a setting if it exists.
- **View Settings:** Displays all current settings or a message if no settings are available.
- **Case Normalization:** Converts setting names and input values to lowercase when adding or updating settings.

### What I Learned  
Through this project, I practised:  
- Creating and calling functions.
- Adding, updating, and deleting dictionary entries.
- Working with tuples and iterating through their elements.
- Using conditional statements to handle different situations.
- Formatting strings and returning descriptive messages.
- Handling cases where a setting already exists or cannot be found.
